# Assets Directory

This directory contains images and media files for the GitHub Pages landing page.

## Required Images

### 1. extension-popup.png
- **Purpose:** Screenshot of the extension popup interface
- **Dimensions:** 800x600px recommended
- **Content:** Show the extension popup with extracted trophy data
- **How to create:** Take a screenshot of the extension popup on a TrueTrophies page

### 2. csv-export.png
- **Purpose:** Example of exported CSV data
- **Dimensions:** 800x600px recommended
- **Content:** Show a spreadsheet or text editor with exported CSV data
- **How to create:** Open exported CSV in Excel/Google Sheets and take screenshot

### 3. truetrophies-page.png
- **Purpose:** TrueTrophies page with extension active
- **Dimensions:** 1200x800px recommended
- **Content:** Show a TrueTrophies game page with extension icon visible
- **How to create:** Take a screenshot of a TrueTrophies game trophy page

### 4. extension-preview.png
- **Purpose:** Main preview image for social media and store listings
- **Dimensions:** 1200x630px (Facebook/Twitter optimal)
- **Content:** Composite image showing the extension in action
- **How to create:** Create a montage showing the extension popup and CSV export

## Image Guidelines

- **Format:** PNG preferred for screenshots, JPG for photos
- **Size:** Optimize for web (under 500KB each)
- **Quality:** High resolution, clear and readable text
- **Consistency:** Use similar styling and colors across all images
- **Accessibility:** Ensure good contrast and readable text

## Creating Screenshots

### Extension Popup Screenshot
1. Navigate to a TrueTrophies game trophy page
2. Click the extension icon to open the popup
3. Extract some trophy data
4. Take a screenshot of the popup interface
5. Crop to focus on the popup (remove browser chrome)

### CSV Export Screenshot
1. Export trophy data to CSV using the extension
2. Open the CSV file in Excel, Google Sheets, or a text editor
3. Take a screenshot showing the structured data
4. Ensure trophy names, types, and other data are visible

### TrueTrophies Page Screenshot
1. Navigate to a popular game's trophy page on TrueTrophies
2. Ensure the extension icon is visible in the toolbar
3. Take a full-page screenshot
4. Crop to show the page content and extension icon

### Preview Image
1. Create a composite image using design software
2. Include elements from the popup and CSV screenshots
3. Add the extension name and key features
4. Use consistent branding colors

## File Naming Convention

- Use lowercase letters and hyphens
- Be descriptive but concise
- Include file extension
- Examples: `extension-popup.png`, `csv-export.png`

## Optimization

Before uploading images:

1. **Compress:** Use tools like TinyPNG or ImageOptim
2. **Resize:** Ensure appropriate dimensions for web use
3. **Format:** Convert to web-optimized formats
4. **Test:** Verify images load quickly on the landing page

## Backup

Keep original high-resolution versions of all images in a separate folder for future use and modifications.
